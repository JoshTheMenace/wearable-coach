# CPR practice reference poses

These two photos were captured during the wearer's manikin rehearsal on September 17, 2026. The wearer reviewed each image and confirmed its intended label: `correct.jpg` or deliberately too low in `too-low.jpg`.

They support a comparison for this specific practice setup, not a general CPR assessment or clinical ground truth. The current frame must show the same manikin and a clear hand position to match either example; otherwise the check returns unclear.

Only these two selected references are bundled. Raw calibration frames and session logs remain outside Git. A complete pair in `.runtime/cpr-placement-reference/` overrides these files after a backend restart.
