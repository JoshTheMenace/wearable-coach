# Synthetic Wargame Learning Analysis package

SYNTHETIC — NOT AN ACTUAL TRAINEE EVALUATION

This package contains six fictional Threshold evidence artifacts and one fictional tabletop artifact. They exercise decision-time evidence handling, instructor-context gaps, outcome/process separation, contradictory evidence, and partial capture. They do not represent real trainees, units, records, or validated assessment results.

- Import an `.artifact.json` file through the dashboard’s Evidence panel.
- Read `evaluator-keys.json` only for review and regression testing; it is not learner-facing evidence.
- Verify source bytes against `manifest.json` before submitting or demonstrating the package.
- The artifact contract is documented in `../CONTRACT.md`.
