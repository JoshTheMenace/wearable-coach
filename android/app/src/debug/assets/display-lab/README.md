# Display test fixtures

`view0.png` through `view3.png` are abstract, nonclinical 3D test images generated by `android/render-display-lab.py`. Regenerate with Blender before building the APK:

```
blender --background --factory-startup --python-exit-code 1 --python android/render-display-lab.py
```

`clip.mp4` is Meta's public DisplayAccess sample fixture, downloaded September 16, 2026 from:
https://github.com/facebook/meta-wearables-dat-android/raw/refs/heads/assets/video_266x150_faststart.mp4

It contains 266×150 H.264 video and AAC audio, with a reported duration of 5.794 seconds. It is a transport/playback test, not a CPR lesson. See the source repository's license and provenance before redistributing the fixture beyond this development build.
